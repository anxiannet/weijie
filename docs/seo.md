# SEO 规则

## SEO 目标

维界的 SEO 目标不是短期流量，而是逐步覆盖新加坡中国留学生长期搜索的生活问题。

内容应稳定、真实、可验证，并适合长期排名。

## 核心关键词

长期统一使用：

- 新加坡留学
- 新加坡租房
- 新加坡留学生
- NUS租房
- NTU租房
- SMU租房
- 新加坡学生公寓
- 新加坡生活
- 新加坡美食

## 第二阶段 SEO 页面

优先建设：

- NUS 租房
- NTU 租房
- SMU 租房
- 新加坡学生公寓
- 新加坡留学生美食
- 新加坡租房攻略
- 新加坡生活指南

## 页面标题规则

标题应清晰直接，避免夸张语气。

推荐格式：

- NUS 租房指南｜维界
- 新加坡学生公寓｜维界
- 新加坡留学生美食地图｜维界
- 新加坡租房攻略｜维界

避免：

- 全网最全 NUS 租房攻略
- 新加坡租房必看
- 留学生租房神器
- 爆火学生公寓推荐

## 描述规则

Meta description 应说明页面提供什么信息、服务谁、有什么结构价值。

推荐表达：

面向新加坡留学生整理 NUS 周边租房区域、通勤、预算与注意事项，帮助学生更清晰地比较房源。

避免情绪化、夸张或过度承诺。

## 技术要求

页面应优先满足：

- SSR
- 静态生成
- 结构化数据
- Sitemap
- Schema.org
- 清晰 canonical
- 移动端可读性

## 内容原则

SEO 页面必须：

- 真实
- 可验证
- 长期有效
- 本地化
- 去营销化
- 有明确结构

## 内容结构建议

每个 SEO 页面建议包括：

- 页面介绍
- 适合人群
- 关键信息摘要
- 详细分区
- 注意事项
- 常见问题
- 相关页面入口

## 禁止方向

禁止为了 SEO 生成低质量堆词内容。

禁止为了排名编造不可验证信息。

禁止使用“最全”“必看”“神器”等营销词。
