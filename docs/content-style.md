# 内容与文案风格

## 总原则

维界的内容应像一个清晰、可信、结构化的生活系统，而不是公众号或营销号。

所有用户可见文案默认使用中文。

## 内容气质

文案应体现：

- 简洁
- 清晰
- 克制
- 专业
- 有秩序
- 信息优先
- 本地化
- 长期有用

## 推荐表达

使用具体、可执行、低情绪的表达。

示例：

- 查看真实房源、学生公寓与合租信息，快速找到适合自己的住所。
- 了解新加坡高校、课程强度、生活体验与学生评价。
- 收集适合日常聚餐、课后简餐和周末探索的餐厅与食阁。
- 获取校园活动、聚会、兼职与本地社交信息。

## 避免表达

避免：

- 全网最全
- 必看
- 神器
- 爆款
- 超值
- 震惊
- 绝了
- 冲
- 薅羊毛
- 不看后悔

避免过度承诺：

- 保证找到房
- 一定省钱
- 最靠谱
- 最便宜
- 最高性价比

## 标题规则

标题要说明内容本身，不制造情绪。

推荐：

- 新加坡留学生租房怎么选：预算、通勤与合同注意事项
- 抵达新加坡第一周：电话卡、银行卡、交通卡与生活采购
- 新加坡留学生美食地图

避免：

- 新加坡租房避坑必看
- 全网最全新加坡生活攻略
- 留学生必备神器

## 页面说明

页面说明应回答：

- 这个页面是什么
- 给谁使用
- 能解决什么问题

不要写成广告语。

## 列表卡片

卡片内容应优先展示可比较信息：

- 地点
- 类型
- 价格
- 时间
- 分类
- 适合人群
- 关键标签

## 详情页

详情页应提供：

- 清晰标题
- 核心摘要
- 关键信息
- 结构化详情
- 下一步入口

## 语言习惯

使用自然中文。

可以保留新加坡本地常见英文缩写：

- NUS
- NTU
- SMU
- SUTD
- MRT
- HDB
- Condo

但不要把整段用户文案写成英文。
