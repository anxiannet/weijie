# 前端规范

本文件约束维界项目的前端实现。

## 技术栈

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui 风格组件
- lucide-react 图标

## 基本原则

- 移动端优先
- 响应式布局
- 信息结构清晰
- 少装饰
- 保持系统感
- 避免营销页式大幅堆叠

## 页面体验

页面应优先服务真实使用场景。

对于工具型页面，例如房源中心、学校信息、美食地图、活动中心，应避免首页式品牌大段介绍。

工具页应优先展示：

- 搜索
- 筛选
- 列表
- 状态
- 关键操作

## 视觉规则

使用：

- 留白
- 清晰分区
- 稳定卡片
- 明确导航
- 克制颜色
- 一致间距

避免：

- 低质渐变
- 装饰性图形堆叠
- 过大的营销 Hero
- 不必要的动画
- 文字遮挡
- UI 元素重叠

## 组件规则

优先复用现有组件：

- Button
- Card
- Badge
- Input
- Select
- Sidebar

图标优先使用 lucide-react。

不要手写复杂 SVG 图标，除非项目已有类似模式或用户明确要求。

## 内容规则

用户可见文案默认中文。

文案保持：

- 简洁
- 克制
- 信息优先

避免营销腔。

## 列表页

列表页应包含：

- 标题
- 简短说明
- 卡片列表
- 关键标签
- 详情入口

列表卡片应保持可扫描性。

## 详情页

详情页应包含：

- 返回入口
- 大图或主要视觉
- 标题
- 摘要
- 关键信息卡片
- 结构化详情内容

美食、活动、学校、指南等内容都应尽量有详情页。

## 图片

图片来源：

- Cloudflare R2
- 已批准的远程图片
- public 目录中的静态资源

房源图片上传使用 Cloudflare R2。

远程图片展示时，如未配置 Next Image 域名，应使用 `unoptimized` 或补充配置。

## 可访问性

按钮和链接应有清晰语义。

图标按钮需要可理解的 `aria-label`。

表单字段应有明确 placeholder 或 label。

## 验证

前端改动后优先执行：

- `npm run typecheck`

涉及页面展示时，应在浏览器或本地 URL 中验证关键页面可访问。
